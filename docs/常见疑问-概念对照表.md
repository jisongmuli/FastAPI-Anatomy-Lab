# 常见疑问 · 概念对照表（初学者的 24 个卡点）

> 用法：读代码时遇到不认识的写法，先来这里查。每条都是"**长什么样 → 怎么读 → 一句话例子**"。
> 这些就是你作为"读代码的人"需要跨过的坎，不需要会写。

---

## 一、Python 语法层

### 1. 类型提示（Type Hints）：`name: str`、`-> dict`
```python
def create(title: str, priority: int = 3) -> dict:
```
**怎么读**：冒号后面是"给人看的说明书"，箭头是"返回值是什么"。
**关键**：Python 运行时**不强制**检查它。但对 FastAPI 来说它是**真正的功能**（自动校验 + 自动生成文档）。
**看到就想**：这个函数要什么、吐什么。

### 2. 装饰器：`@something`
```python
@app.get("/health")
@pytest.fixture()
@property
```
**怎么读**：`@xxx` 是"给下面的函数贴标签/登记"。真正干活的还是 `def`。
**三种最常见**：`@app.xxx` 注册接口 / `@pytest.fixture` 准备测试数据 / `@property` 把方法当属性。

### 3. `self` 是什么
```python
class Task:
    def finish(self):
        self.done = True
```
**怎么读**：`self` = "这个对象自己"。`self.done` 就是"我自己的 done 属性"。
**技巧**：读类的时候把 `self.xxx` 当成"这个表的某个字段"。

### 4. `if __name__ == "__main__":`
```python
if __name__ == "__main__":
    uvicorn.run(app)
```
**怎么读**："如果这个文件是被**直接运行**的，就执行下面这段；如果它是被 import 的，就跳过。"
**为什么要有**：让同一个文件既能当模块导入，又能当脚本直接跑。

### 5. 列表推导式：`[x for x in items if 条件]`
```python
titles = [t.title for t in tasks if t.status == "done"]
pending = [u for u in users if u["role"] == "student"]
```
**怎么读**：从右往左读 —— "遍历 tasks，筛出 done 的，取出 title，组成一个新列表"。
**等价于**：
```python
titles = []
for t in tasks:
    if t.status == "done":
        titles.append(t.title)
```
看到推导式不要慌，脑内展开成 for 循环即可。

### 6. `*args` 和 `**kwargs`
```python
def log(*args, **kwargs): ...
repository.create(session, **changes)
```
**怎么读**：`*args` = "任意多个位置参数"，`**kwargs` = "任意多个关键字参数"。
**调用处看到 `**changes`**：意思是"把这个字典**拆开**当关键字参数传进去"，
即 `{"title": "a"}` 变成 `create(title="a")`。这叫"解包"。

### 7. `Optional[str]` 和 `str | None`
```python
description: Optional[str] = None
description: str | None = None          # 新写法，完全等价
```
**怎么读**："这个字段**可以是** None（即可以不传/可以为空）"。
**重点**：`Optional[X]` **不代表**"可选参数"，它只表示"值可以是 None"。是否必填看有没有 `= None` 默认值。

### 8. f-string：`f"任务 {id} 不存在"`
```python
raise TaskNotFound(f"任务 {task_id} 不存在")
```
**怎么读**：字符串前面带 `f`，里面 `{}` 的内容会被替换成变量的值。
**看到就想**：这是拼字符串，`{}` 里是变量名。

### 9. 字典的 `get` 与 `[]`
```python
user["name"]        # 键不存在 → 直接报错 KeyError
user.get("phone")   # 键不存在 → 返回 None，不报错
changes.get("status") != "pending"
```
**怎么读**：`get` 更安全。看到 `get("x", 默认值)` 就是"取不到就给个默认值"。

### 10. `with` 语句（上下文管理器）
```python
with engine.connect() as conn:
    conn.execute(text("SELECT 1"))
with TestClient(app) as client:
    ...
```
**怎么读**："用这个资源，用完自动收拾干净（关闭/释放）。"
**看到就想**：这里涉及"资源管理"，`with` 保证异常时也能正确释放。

### 11. `try / except / finally` 与 `raise`
```python
try:
    yield session
finally:
    session.close()

raise TaskNotFound(task_id)
```
**怎么读**：`try` 里是"正常流程"，`except` 是"出错了走这里"，`finally` 是"无论如何都执行"。
`raise` = **主动抛出错误**。在后端里，`raise 自定义异常` 会被 `errors.py` 翻译成 HTTP 状态码。

### 12. `async` / `await`
```python
async def health_check(): ...
async def _validation_error(request, exc): ...
```
**怎么读**："这是异步函数，执行时可以让出时间去做别的事（适合等网络/IO）。"
**你只需要知道三点**：
1. FastAPI 里 `def` 和 `async def` 都能写接口，都能正常工作
2. `async def` 里要调用另一个异步函数，必须加 `await`
3. 不需要为了"性能"把所有函数都改成 async —— 用错了反而更慢

### 13. `yield` 生成器
```python
def get_session():
    session = SessionLocal()
    try:
        yield session        # ← 把值交出去，暂停在这里
    finally:
        session.close()      # ← 调用方用完后，回到这里继续
```
**怎么读**："这个函数不是一次执行完，而是在 `yield` 处**暂停并交出值**，等别人用完再回来收尾。"
**看到就想**：`yield` 前是准备工作，`yield` 后是清理工作。FastAPI 的依赖就靠这个实现"用完自动关连接"。

### 14. `Annotated[X, ...]`
```python
DbSession = Annotated[Session, Depends(get_db)]
```
**怎么读**："类型是 Session，同时附带一条附加说明：**它由 get_db 提供**。"
它只是把"类型 + 依赖声明"打包成一个短名字，让函数签名更干净。

## 二、Web / FastAPI 层

### 15. HTTP 方法：GET / POST / PUT / PATCH / DELETE
| 方法 | 语义 | 幂等? | 例子 |
|---|---|---|---|
| GET | 读取 | 是 | 查列表、查详情 |
| POST | 新建 / 触发动作 | 否 | 新建任务、标记完成 |
| PUT | **整体**替换 | 是 | 整个对象重写 |
| PATCH | **局部**更新 | 否 | 只改 priority |
| DELETE | 删除 | 是 | 删任务 |
**怎么读**：看到 PUT 就找"是不是要传全部字段"，看到 PATCH 就找"是不是只改传了的字段"。

### 16. 路径参数 / 查询参数 / 请求体
```python
@app.get("/users/{user_id}")           # 路径参数：在网址里
def f(user_id: int, role: str = None,   # 查询参数：不在网址路径里
      payload: UserCreate = ...):       # 请求体：类型是 BaseModel 子类
```
**判断口诀**：名字在 `@app.xxx("...")` 里 → 路径参数；类型是 BaseModel → 请求体；**剩下的都是查询参数**。

### 17. 常见状态码
`200` 成功 / `201` 创建成功 / `204` 删除成功（响应体为空）/ `400` 请求有误 /
`401` 未登录 / `403` 无权限 / `404` 不存在 / `409` 业务冲突 / `422` 参数校验失败 / `500` 代码 bug。
（详细读法见 Day2 讲义第 9 节）

### 18. `response_model` 与 ORM 对象的关系
```python
@router.post("", response_model=TaskRead)
def create_task(payload: TaskCreate, db: DbSession):
    return service.create_task(db, payload)     # 返回的是 SQLAlchemy 的 Task 对象
```
**怎么读**：函数返回的是**数据库对象**，FastAPI 按 `response_model` 把它转成 JSON，并且**过滤掉多余的字段**。
`model_config = ConfigDict(from_attributes=True)` 就是"允许从对象属性里取值"的开关。

### 19. 依赖注入（DI）
```python
def list_tasks(db: DbSession, page: PageParams): ...
```
**怎么读**："这些参数不用调用方传，框架会准备好。"
**最大价值**：测试时可以替换（`app.dependency_overrides`）——这就是测试能用内存数据库的原因。

### 20. Pydantic 模型 vs SQLAlchemy 模型（最容易混的一对）
| | Pydantic（`schemas.py`） | SQLAlchemy（`models.py`） |
|---|---|---|
| 干什么 | 校验/序列化**接口数据** | 映射**数据库表** |
| 生命周期 | 一次请求 | 长期存在 |
| 典型名 | `TaskCreate` / `TaskRead` | `Task` |
| 能存数据库吗 | 不能 | 能 |
**为什么必须分开**：表里可能有 `password_hash`，接口绝不能返回。分开才能"表里有、接口不给"。

### 21. `session.add` / `commit` / `refresh` / `rollback`
```python
session.add(task)        # 加入"待写入"队列（还没进数据库）
session.commit()         # 真正写进去
session.refresh(task)    # 回读一次，拿到数据库生成的 id / 时间戳
session.rollback()       # 撤销本次未提交的改动
```
**读代码关键**：**只有 commit 之后数据才真的在数据库里**。
这就是"接口返回 201 但查不到数据"这类 bug 的根源。

### 22. `Depends` + `yield` 的执行顺序
```
请求进来
  → get_db() 执行到 yield，把 session 交给接口
  → 接口函数跑完
  → 回到 get_db() 的 finally，关闭 session
```
**记住**：依赖的收尾代码在**响应返回之后**才执行。

## 三、工程 / 环境层

### 23. 虚拟环境（venv）：为什么要有 `.venv`
**问题**：A 项目要 fastapi 0.100，B 项目要 fastapi 0.141，装在同一个 Python 里必然冲突。
**解决**：每个项目一个独立小盒子 `.venv`，互不干扰。
```powershell
python -m venv .venv                  # 建盒子
.\.venv\Scripts\Activate.ps1          # 进盒子（提示符前出现 (.venv)）
pip install -r requirements.txt       # 只装进这个盒子
deactivate                            # 出盒子
```
**看到就想**：`.venv/` 是本项目的私有依赖，**绝对不要提交到 git**（见 `.gitignore`）。
**常见坑**：PyCharm/VSCode 里要手动把解释器指向 `.venv\Scripts\python.exe`，否则 IDE 会报"找不到 fastapi"。

### 24. `requirements.txt` / `pyproject.toml`
```text
fastapi>=0.109,<1.0
uvicorn>=0.27,<1.0
```
**怎么读**：`>=` 是下限，`<` 是上限（锁住大版本，防止自动升到不兼容的新版）。
**用途**：别人拿到你的项目，`pip install -r requirements.txt` 就能装齐依赖。

## 四、附：三条"看到就警觉"的代码信号

读陌生项目时，遇到这些要特别小心（可能是 bug 或安全隐患）：

| 信号 | 为什么警觉 |
|---|---|
| `except Exception: pass` | 把错误**吞掉**了，出问题你永远查不到原因 |
| 硬编码密码/密钥 `SECRET = "abc123"` | 应该从环境变量或 `.env` 读，硬编码会泄露到 git |
| `SELECT *` 或 `.all()` 后没分页 | 数据一多就会拖垮服务 |
| 在循环里查数据库（N+1 查询） | 100 条数据发 101 次查询，性能灾难 |
| 接口直接返回 ORM 对象且没有 `response_model` | 可能泄露表里的敏感字段 |
| 没有 `try/finally` 就开连接/开文件 | 出异常时资源不会释放 |

**这份清单本身就是"代码审查"的雏形** —— 以后 AI 给你生成代码，你就用这几条去挑毛病。
